# uNdoqo V2.7 release report

**Scope:** operational recovery and private digital-asset activation, not a site redesign.

## Implemented

- `netlify/functions/admin-reconcile.js`: authenticated sandbox-only inspect/reconcile operations for already-captured PayPal orders; explicit check of PayPal order ID, `custom_id`, USD amount, currency and single completed capture; never initiates capture.
- `netlify/functions/_lib/admin-auth.js`: constant-time admin-secret check for the recovery and asset endpoints.
- `netlify/functions/admin-assets.js`: private asset inventory, disabled PDF registration after verifying its storage metadata, and explicit activation through the V2.6 RPC.
- `pages/orders-admin.html` + `js/admin-orders.js`: administrator workflows for capture inspection/reconciliation and asset registration/activation.
- `tests/v27.test.js`: logic and mocked integration tests for recovery, validation and asset registration.
- `V2.7_SETUP.md`: detailed implementation, safety and release steps.

## Preserved

The original navigation, logos, Contact page, checkout UI, prices, V2.6 customer order status, signed-download endpoint and existing Supabase database schema are retained.

## Deferred/external actions

Existing pending transactions remain unchanged until an authorized administrator reconciles each one against PayPal. Licensed PDFs are not bundled. PayPal live webhook and email delivery are not connected by this archive. Real environment verification is still required.
